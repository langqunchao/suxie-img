# 人物头像素材库

> 为绘画爱好者打造的在线人物摄影参考工具。

## 两种使用模式

### 模式一：无限随机模式（推荐）

每次点击都从 Unsplash 官方图库调取**全新的人像摄影**，真正做到无限不重复。

**申请免费 API Key（只需 30 秒）：**
1. 打开 https://unsplash.com/developers
2. 用 GitHub 账号登录（或注册）
3. 点击 "New Application"，勾选同意条款
4. 复制 **Access Key**
5. 打开 `js/app.js`，找到 `const UNSPLASH_ACCESS_KEY = '';`，把 Key 填入引号中
6. 刷新页面即可

**免费版额度：** 每小时 50 次请求，个人绘画练习完全够用。

### 模式二：离线备用池模式

不填 API Key 也能直接使用。内置 **60+ 张精选高清人像摄影**，配合 Fisher-Yates 随机洗牌 + 近期去重算法，切换体验也很流畅。

## 功能特性

- 一键切换人物摄影素材，支持鼠标点击和键盘空格键
- 支持 Unsplash 官方 API 无限随机模式（需免费 Key）
- 内置 60+ 张备用高清人像池，零配置即用
- 点击图片可在新标签页查看原图
- 自动加载动画和错误降级处理
- 深色画室主题，响应式适配桌面和移动端

## 快速开始

直接在浏览器中打开 `index.html` 即可使用，无需安装任何依赖或构建工具。
